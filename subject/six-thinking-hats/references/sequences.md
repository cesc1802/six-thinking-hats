# Hat sequences by decision type

Blue always opens and closes. The order of the middle hats changes with the purpose of the session. State the chosen sequence in the Blue-open section and why.

| Purpose | Sequence | Why this order |
|---|---|---|
| **Default — evaluate an option / proposal** | Blue → White → Red → Yellow → Black → Green → Red → Blue | Facts first; early Red exposes bias; Yellow before Black so benefits are on the table when risks are weighed; Green answers Black; late Red checks whether analysis moved the gut. |
| **Workbook order (product development case)** | White → Black → Yellow → Red → Blue → Green | The book puts Black immediately after White so risks constrain the optimism that follows, and ends on Green so the session finishes generative. Use when the team tends toward over-optimism. |
| **Generate ideas / brainstorm** | Blue → White → Green → Yellow → Black → Green → Blue | Green early and unjudged; Yellow/Black then sort ideas; second Green improves survivors. |
| **Risk review / pre-mortem** | Blue → White → Black → Green → Yellow → Blue | Black is the focus, but Green must follow it so the session produces mitigations, not just a risk list. |
| **Retrospective (sprint / project / incident)** | Blue → White → Red → Yellow → Black → Green → Blue | White anchors on what actually happened (timeline, metrics); Red before analysis lets people say how it felt; Yellow before Black keeps the retro blameless. |
| **Go / no-go (bid, contract, release)** | Blue → White → Yellow → Black → Red → Blue | Red placed late and once: after facts and both sides, ask "do we want this?" — gut is a legitimate tiebreaker on a bid. |
| **Resolving a conflict between two camps** | Blue → Red → White → Yellow (for each option) → Black (for each option) → Green → Blue | Red first so emotions are named, not acted out; Yellow and Black applied symmetrically to *both* options prevents the usual "my benefits vs your risks". |
| **Improve an existing plan** | Blue → White → Black → Green → Yellow → Blue | Find the weak points, fix them, then confirm the plan still delivers value. |

## Time boxes (facilitate mode)

For a 60-minute human session on one decision:

| Hat | Minutes |
|---|---|
| Blue open | 5 |
| White | 10 |
| Red | 2 (written, silent) |
| Yellow | 10 |
| Black | 10 |
| Green | 10 |
| Red check | 2 |
| Blue close | 11 |

Scale proportionally. Red never gets more than 2–3 minutes; if it needs more, something is wrong upstream (usually the problem is not framed).
